# Uso de AI

Esta carpeta contiene capturas relacionadas con el uso de herramientas de inteligencia artificial durante el desarrollo del proyecto.

## Propósito del uso de IA

La IA se utilizó como apoyo educativo y técnico para:

- aprender conceptos de JavaScript, Vite, APIs, funciones serverless y testing;
- realizar consultas sobre arquitectura, organización del código y experiencia de usuario;
- analizar errores y proponer alternativas de solución;
- corregir y mejorar código existente;
- revisar la integración con Gemini y el límite de tokens;
- documentar decisiones y comprender mejor el funcionamiento de la aplicación.

Las sugerencias recibidas no se implementaron automáticamente. Cada propuesta fue revisada, probada y adaptada al proyecto antes de incorporarla. También se verificó que los cambios fueran coherentes con la estructura existente y que no introdujeran errores en las funcionalidades implementadas.

Las imágenes de esta carpeta sirven como registro visual de consultas, revisiones y parte del proceso de desarrollo asistido por IA.
